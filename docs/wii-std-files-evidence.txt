Descriptor/online checks precede metadata writes. Clean read-only files do not
rewrite their directory entry. Dirty state clears only after successful metadata
and transport completion. Close releases ownership after flush failure and
invalidates magic/mount fields so the handle cannot release twice.

and close preserve all attributes and writable open returns ReadOnly. Original
attributes are restored even after a failed operation; restore failure is logged.
The USB persistence probe reopens read-only and checks sync/close. Existing
hotplug handling now validates failed fsync and close after SD/USB removal.

acceptance is still open; no disconnection test has run on real hardware.
