# ISO9660 API runtime audit

This audit maps each public Rust function in `crates/media/iso9660` to a
Dolphin assertion. The evidence is the `runtime_probe` log in
[`iso-file-boundaries`](iso-file-boundaries/probe.log). That Wii-mode run
reported 105 passes and no failures. It used a fixed in-memory ISO image. It
tests the filesystem interface over the controlled image; it does not test a
disc drive or a physical disc.

| Rust API | Runtime assertion | Result and limit |
| --- | --- | --- |
| `mount` | `Rust filesystem ISO mount` | Pass; mounted the test image as `isfs`. |
| `volume_label` | `Rust filesystem ISO volume label` | Pass; returned `TESTVOL`. |
| `unmount` | `Rust filesystem ISO unmount` and `Rust filesystem ISO cleanup` | Pass; unmount succeeded and the label lookup returned null. |
| `iso9660_mount` | `ISO9660 Rust C wrappers mount read the label and unmount the volume` | Pass as part of the wrapper lifecycle assertion. |
| `iso9660_get_volume_label` | `ISO9660 Rust C wrappers mount read the label and unmount the volume` | Pass as part of the wrapper lifecycle assertion; the label matched `TESTVOL` and cleared after unmount. |
| `iso9660_unmount` | `ISO9660 Rust C wrappers mount read the label and unmount the volume` | Pass as part of the wrapper lifecycle assertion. |

The same log records file reads, seek position, read after seek, EOF buffer
preservation, write rejection, missing-file `ENOENT`, close, stat, and root
directory changes. Those checks exercise the file-system callbacks used by
the mounted device. The log also checks that all four C exports reject null
arguments. The wrappers share one lifecycle assertion, so that assertion does
not isolate each wrapper's return value by itself.

`docs/generated/implementation-inventory.csv` lists nine inventory rows for
this package. It includes C export and Rust function rows. The table above
maps the six public Rust functions. The API wrappers and their C aliases use
shared implementation paths; the grouped assertions do not establish a
separate runtime assertion for every inventory row. Physical DVD reads,
partition reads, and the drive callback path remain open.
